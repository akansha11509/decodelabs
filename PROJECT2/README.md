# Iris Flower Classification using Machine Learning

This is a beginner-friendly machine learning project that classifies Iris flowers into three species (*Setosa*, *Versicolor*, and *Virginica*) based on four physical measurements: sepal length, sepal width, petal length, and petal width.

The project utilizes the **Random Forest Classifier** algorithm provided by the `scikit-learn` library.

## 🛠️ Tools and Libraries Used
- **Python** - **Pandas** & **NumPy** (Data manipulation)
- **Scikit-learn** (Machine Learning framework)
- **Seaborn** & **Matplotlib** (Data visualization)
